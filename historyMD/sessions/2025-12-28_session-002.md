## 🐛 BUGS CRÍTICOS DESCUBIERTOS Y RESUELTOS

### **BUG #1: Patient Context Missing in Specialist Conversations**

**Severidad:** 🔴 **CRÍTICA** (Seguridad del paciente)

**Descripción:**  
El contexto del paciente (alergias, medicación actual, antecedentes) se inyectaba correctamente en:
- ✅ Triaje inicial (`triage_agent.evaluate()`)
- ✅ Evaluación de especialistas (`specialist_agent.evaluate()`)

Pero **NO** se inyectaba en:
- ❌ Conversaciones con especialistas (`specialist_agent.chat()`)

**Impacto:**  
Un especialista podía recomendar Penicilina a un paciente alérgico en una conversación de seguimiento, incluso cuando el sistema tenía esa información registrada.

**Root Cause:**  
El método `BaseMedicalAgent.chat()` no aceptaba el parámetro `patient_context`, y `specialist_chat_node()` no lo pasaba.

**Solución:**

**Archivo:** `src/agents/base_agent.py`
```python
# ANTES:
async def chat(self, message: str, session_id, history: list[Message]) -> str:

# DESPUÉS:
async def chat(
    self, message: str, session_id, history: list[Message], 
    patient_context: Optional[str] = None
) -> str:
    # ...
    if patient_context:
        messages.append({"role": "system", "content": patient_context})
        logger.info(f"✅ {self.specialty}: Contexto del paciente INYECTADO en el chat")
```

**Archivo:** `src/graph/nodes.py`
```python
# specialist_chat_node (línea ~269)
response = await agent.chat(
    message=last_user_message.content,
    session_id=state.session_id,
    history=state.messages,
    patient_context=state.patient_context,  # ✅ AÑADIDO
)
```

## 💡 LECCIONES APRENDIDAS

### **1. Context Injection is Critical in Medical AI**
Un bug en la inyección de contexto puede tener consecuencias médicas graves. El test E2E que verifica alergias debería ser **obligatorio** en CI/CD.

### **2. Type Annotations Prevent Runtime Bugs**
El bug de `patient_context` en `chat()` habría sido detectado antes con type checking estricto. Mypy sí lo detectó, pero lo ignoramos por priorizar velocidad.

**Acción:** Habilitar mypy strict mode gradualmente (por módulo).

### **3. Test Data Should Be Production-Like**
Crear un paciente con alergias reales en el test E2E fue clave para descubrir el bug. Los tests con datos genéricos no habrían mostrado el problema.

### **4. Git Commit Messages Matter**
Los commits detallados (`fix: inject patient_context...`) facilitan el debugging. Alguien revisando el historial en 6 meses entenderá exactamente qué se arregló y por qué.
