## 5. Important Decisions

### Decision: CI/CD Configuration Strategy

**Context:** Need to balance code quality enforcement with development velocity

**Options considered:**
1. ❌ Strict mypy/ruff (block on any warning)
2. ✅ **Chosen:** Non-blocking linters, blocking tests
3. ❌ No CI/CD (manual quality checks)

**Reasoning:**
- Medical application requires HIGH test coverage (safety-critical)
- Type hints and linting improve quality but shouldn't block emergency fixes
- Security scans inform but don't block (many false positives)
- Tests MUST pass (patient safety depends on correctness)

**Implementation:**
```yaml
# Lint/type jobs
continue-on-error: true  # Warn but don't fail

# Test job
continue-on-error: false  # MUST pass
```
