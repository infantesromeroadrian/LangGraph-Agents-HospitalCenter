## 4. Decisiones Técnicas

### Uso de Send API para Paralelismo

**Contexto**: Necesidad de evaluar 8 especialistas simultáneamente

**Decisión**: Usar `langgraph.types.Send` en `fan_out_to_specialists`

**Ventajas**:
- Ejecución verdaderamente paralela
- Reducción de latencia de ~16s (secuencial) a ~3s (paralelo)
- Integración nativa con LangGraph

### AsyncPostgresSaver para Checkpointing

**Contexto**: Memoria persistente y recuperación de estado

**Decisión**: Usar `AsyncPostgresSaver` nativo de LangGraph

**Ventajas**:
- Soporte oficial de LangGraph
- Checkpointing automático
- Async-friendly para Flask
- Tablas optimizadas para el caso de uso

### WebSocket para Streaming

**Contexto**: Usuario requiere ver progreso en tiempo real

**Decisión**: Flask-SocketIO con gevent

**Ventajas**:
- Streaming de eventos del grafo
- Actualización UI en tiempo real
- Compatible con async/await
- Fácil integración con Flask
